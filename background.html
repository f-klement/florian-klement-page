Infrastructure Background

Background

What I have been responsible for, and what trained me for it

The overview page says what I do. This page says what that has meant in practice: the responsibilities I have carried across data, delivery and platform work, the studies behind them and the courses taken since. Grouped by theme rather than by station, because the themes are what carry over.

Responsibilities

Application modernisation

Bringing legacy systems into the present without stopping the business that runs on them.

  • Designed and built web frontends in TypeScript and React, on Bun, to replace ageing interfaces.
  • Containerised legacy and greenfield applications with Docker and deployed them to Kubernetes through custom Helm charts.
  • Designed SQL schemas and ETL pipelines that move complex datasets from legacy structures to current standards without loss.

Delivery automation

Pipelines that build, test and ship, so that a release stops being an event.

  • Engineered GitLab CI pipelines and Bash tooling that build, archive and deploy artifacts, cutting manual release work.
  • Standardised local and CI environments with Docker Compose so that development matched production.
  • Established quality gates with SonarQube static analysis and Playwright end-to-end tests.

Traffic & developer tooling

The layer between the network and the code, and the tools that make it visible.

  • Configured Nginx and Traefik for reverse proxying and dynamic service discovery.
  • Built Python (Flask) API wrappers around command-line monitoring tools, giving developers a web view of application health.
  • Run the same patterns privately: a GitOps-managed Kubernetes platform with full observability and layered security.

Data warehousing & pipelines

One source of truth built from scratch, and the pipelines that keep it filled.

  • Architected a unified data warehouse from the ground up, with a schema built for aggregation and anonymisation, as the central source for analysts.
  • Developed Python and SQL pipelines for ingestion and for large-scale external extracts over SFTP.
  • Optimised high-load SQL databases and wrote migration scripts that brought unstructured product data into existing patterns.
  • Built pipelines for parsing, normalising and standardising address data, and matched messy address stocks against geographic hierarchies and coordinates.

Data quality & reporting

Knowing the data is right before anyone builds on it, and showing what it says.

  • Implemented statistical monitoring and threshold-based alerting in R and Python to catch ingestion errors and product incidents before they reached a report.
  • Delivered performance insights through custom dashboards (SSRS, Python) and ad-hoc visualisations.
  • Served as the first contact for external stakeholders, turning requirement analysis into data deliveries.

Requirements & stakeholders

Translating between the people who need software and the people who build it.

  • Acted as technical mediator for end users, translating qualitative requirements into precise technical specifications.
  • Defined data specifications with product owners and finalised feature scopes.
  • Worked as the established interface between business units and engineering.

Security hardening & standards

Making the secure configuration the default one, across teams.

  • Co-authored guidelines for Docker deployments, security hardening and standardised server configuration with colleagues from other units.
  • Moved container workloads from rootful to rootless Docker, with SELinux integration and standardised UID/GID namespace mapping.
  • Wired a central artifact repository for container images into the build and deploy pipelines.

Knowledge sharing & mentoring

Documentation that outlives the meeting, and colleagues who can take a stack over.

  • Contributed a React and TypeScript frontend as an internal reference stack, with architecture, tooling, design decisions and operations documented in writing.
  • Kept GitLab wikis, Markdown architecture notes and structured issue threads as the shared record of decisions.
  • Mentored interns and a junior engineer through onboarding and day-to-day code work.

Studies

M.A. Digital Humanities

Focus on NLP and data science · University of Vienna

The thesis built a full NLP pipeline, from tokenisation and embeddings to LDA topic modelling and network analysis, over a corpus of gothic fiction. Alongside it: a legacy text-analysis toolset refactored from Perl to Python, and a weakly supervised NER model for medical text built with PyTorch and Knodle. Performance scholarship; degree with distinction.

B.A. Comparative Literature

Applied literary studies · University of Vienna

Close reading before distant reading. The training in how texts are built is what later made the computational work on them worth doing. Performance scholarship.
